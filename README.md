# 🌦️ Weather & Air Quality Dashboard

An interactive **Weather & Air Quality Analytics Dashboard** that combines real-time weather data with interactive visualizations to provide a clear overview of weather conditions and air quality across multiple cities.

The project includes custom web dashboards built with **HTML, CSS and JavaScript**, along with a **Power BI dashboard** for weather analytics and visualization.

---

## 📊 Project Overview

This project uses weather data from the **WeatherAPI** to create interactive dashboards for:

- 🏙️ Mumbai
- 🏙️ Pune
- 🏙️ Nagpur

The dashboards transform weather and air-quality data into an easy-to-understand visual interface containing current conditions, forecasts, environmental metrics and air-quality indicators.
